# 모바일 반응형 및 로고 정렬 수정

- 모바일(600px 이하, 360px 이하) 화면에서 헤더, 본문, 단계 표시, 검색창, 카드, 버튼의 크기와 줄바꿈 개선
- 가로 스크롤 및 긴 음식점 이름으로 인한 레이아웃 넘침 방지
- 상단 🍽️ 아이콘의 기존 padding 제거, 정중앙 flex 정렬 및 글리프 시각 중심 미세 보정
- 추천, 필터, 카카오 지도, 관련 음식점 검색 및 최근 30회 중복 방지 로직 변경 없음

## 확인
`npm install` 후 `npm run build`, `npm run dev:all` 실행.
모바일 브라우저 또는 개발자 도구에서 320px, 375px, 390px, 430px 화면 확인.
