# 누적 추천 횟수 수정

- 최근 30회 메뉴 기록(`wte-draw-history`)은 중복 방지 전용입니다.
- 총 추천 횟수(`wte-total-draws`)는 별도 저장하고 추천 성공 시에만 1씩 증가합니다.
- 홈으로 돌아가도 최근 30회 기록과 누적 횟수를 초기화하지 않습니다.
- 이전 버전은 최대 30회 기록만 저장했으므로 기존 31회 이상의 실제 과거 횟수는 복원할 수 없습니다. 저장된 총횟수가 없다면 남은 기록 개수(최대 30)를 초기값으로 사용합니다.
- 즐겨찾기에서 기존 메뉴를 여는 것은 새 추천이 아니므로 카운트하지 않습니다.
