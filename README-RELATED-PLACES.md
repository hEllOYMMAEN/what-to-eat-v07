# 관련 음식점 검색 기능

- 정확한 메뉴명으로 카카오 장소 검색 결과가 **0개**일 때만 '관련 음식점 검색' 버튼이 나타납니다.
- 버튼을 누르면 서버가 메뉴명을 더 넓은 검색어(예: 버섯 샌드위치 → 샌드위치, 병아리콩 샐러드 → 샐러드)로 바꾸어 다시 검색합니다.
- 관련 음식점 결과는 실제 메뉴 판매를 보장하지 않으므로 반드시 확인 안내를 표시합니다.
- API 인증 실패·네트워크 오류일 때는 대체 검색 버튼을 표시하지 않습니다.
- 위치/검색 반경/다른 메뉴를 새로 검색하면 기본적으로 정확한 메뉴 검색으로 돌아갑니다.
- 기존 추천 기록, 메뉴 데이터, 아이콘, 카카오 지도 설정은 유지됩니다.

실행: `.env`를 기존 프로젝트에서 복사한 뒤 `npm install`, `npm run dev:all`.
배포: 기존 Git 저장소에 변경 파일을 반영하고 push. Render 환경변수는 그대로 유지.
