# 뭐먹지? v0.7 🍊

v0.5 기반 UI/UX + 카카오 지도. **v0.6 공유 보관함 및 SQLite 기능 없음.**

## 실행 (Windows VS Code CMD)

1. 압축을 풀고 `package.json`이 있는 폴더를 VS Code로 엽니다.
2. `.env.example`을 복사하여 `.env`를 만들고 실제 키로 교체합니다.
   - `KAKAO_REST_API_KEY`: 카카오 REST API 키, Express 서버에서만 사용
   - `VITE_KAKAO_JS_KEY`: 카카오 JavaScript 키, 브라우저 지도 SDK용
3. 카카오 개발자 콘솔에서 **카카오맵 사용 설정** 및 **웹 플랫폼/허용 도메인**에 `http://localhost:5173`, `http://127.0.0.1:5173` 등을 등록합니다. 휴대폰 LAN 접속 주소도 허용 도메인 정책에 맞게 등록해야 할 수 있습니다. 카카오 콘솔의 최신 안내를 확인하세요.
4. CMD에서 실행:

```cmd
npm install
npm run dev:all
```

5. PC에서 `http://localhost:5173` 접속. 휴대폰에서는 같은 네트워크에서 PC의 IP 주소와 포트 5173으로 접속합니다(방화벽/학교망 제한 가능).

## 기능

- 메뉴 데이터, 추천, 필터링은 Express 서버에서 처리
- 카카오 REST API로 지역 검색 및 음식점 검색
- 카카오 JavaScript SDK로 지도/마커 표시, 지도와 목록 선택 동기화
- JavaScript 키 미설정 시 지도 대신 안내 표시, **기존 음식점 목록은 사용 가능**
- 빠른 추천, 상세 조건 접기, 결과 카드 애니메이션, 처음 사용 안내
- 즐겨찾기/최근 기록은 **해당 브라우저의 localStorage에만 저장**

## 주의

- REST 키는 `VITE_` 접두사를 붙이지 마세요. JavaScript 키는 브라우저에 공개되므로 카카오 개발자 콘솔의 허용 도메인을 설정하세요.
- `.env`는 공유하거나 Git에 올리지 마세요.
- 지도는 SDK 로딩을 위해 인터넷 연결이 필요합니다. 음식점은 키워드 검색 결과이며 실제 메뉴 판매 여부는 보장하지 않습니다.
- 스마트폰의 일반 HTTP LAN 접속은 위치 권한이 제한될 수 있으므로 지역명 검색을 사용하세요.
- Vite 개발 서버는 테스트용이며 외부 인터넷에 그대로 공개하지 마세요.
