# 음식점 검색 관련성 개선

- 카카오 검색 결과의 음식점 이름을 바탕으로 명확하게 다른 메뉴의 전문점을 제외합니다.
- 일반 스테이크 추천: 함박/함바그/함바크/햄버그 전문점 이름 제외. 함박스테이크 추천은 제외하지 않습니다.
- 일본식 라멘 추천: 이름에 '즉석라면', '라면전문', '라면집', '분식라면'이 명시된 곳 제외.
- 이름만으로 판매 메뉴를 확정할 수 없으므로 모든 불일치가 제거되는 것은 아닙니다. 반대로 해당 메뉴도 판매하는 음식점이 제외될 수 있습니다.
- 정확 검색 및 관련 음식점 검색 모두 동일한 규칙을 적용합니다. 필터링 후 결과가 0개이면 기존 관련 음식점 검색 버튼이 나타납니다.
- 기존 UI, 추천 기록, 카카오 API 환경변수 사용 방식은 변경하지 않았습니다.
- 테스트: `node --test tests/place-relevance.test.js`
