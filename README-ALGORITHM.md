# v0.8 — 최근 30회 추천 중복 방지

- 패스트푸드별 아이콘 수정 버전을 기반으로 합니다.
- 추천한 메뉴 ID를 순서대로 최근 30회까지 `localStorage` (`wte-draw-history`)에 저장합니다.
- 1번째에 나온 음식은 2~31번째 추첨에서 제외되고, 32번째부터 다른 후보와 같은 확률로 다시 등장할 수 있습니다. **32번째에 반드시 등장하지는 않습니다.**
- 카테고리·연령대·예산·매운맛·식사량·제외 메뉴 조건은 그대로 적용합니다.
- 조건에 맞는 음식이 적어 후보가 소진되면 오래된 기록부터 필요한 만큼만 해제합니다. 이 경우 30회 전에 재등장할 수 있습니다.
- 화면의 '이번 추천에서 제외' 기능은 별도로 유지됩니다.
- 상단 로고는 요청한 접시와 식기 🍽️로 변경하고 메인 도시락 🍱은 유지했습니다.
- 기존 `.env`를 복사한 뒤 `npm install` 및 `npm run dev:all`을 실행하세요.
